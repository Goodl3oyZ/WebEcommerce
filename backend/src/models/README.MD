# รายชื่อตารางและความหมาย

1. **addresses** - ตารางเก็บที่อยู่ของผู้ใช้ (ลูกค้า/ร้านค้า)
2. **brands** - ตารางข้อมูลแบรนด์สินค้า
3. **cart_items** - ตารางรายการสินค้าในตะกร้า
4. **carts** - ตารางข้อมูลตะกร้าสินค้า
5. **categories** - ตารางหมวดหมู่สินค้า
6. **category_discounts** - ตารางส่วนลดตามหมวดหมู่
7. **collection_products** - ตารางความสัมพันธ์ระหว่างคอลเลกชันกับสินค้า
8. **collections** - ตารางคอลเลกชันสินค้า
9. **coupons** - ตารางคูปองส่วนลด
10. **discounts** - ตารางข้อมูลส่วนลดต่างๆ
11. **loyalty_programs** - ตารางโปรแกรมสะสมแต้ม
12. **notifications** - ตารางการแจ้งเตือนผู้ใช้
13. **order_coupons** - ตารางคูปองที่ใช้ในคำสั่งซื้อ
14. **order_items** - ตารางรายการสินค้าในคำสั่งซื้อ
15. **order_status_history** - ตารางประวัติสถานะคำสั่งซื้อ
16. **orders** - ตารางคำสั่งซื้อ
17. **payment_methods** - ตารางวิธีการชำระเงิน
18. **payment_transactions** - ตารางธุรกรรมการชำระเงิน
19. **points_history** - ตารางประวัติการได้/ใช้แต้ม
20. **product_attributes** - ตารางคุณสมบัติสินค้า
21. **product_discounts** - ตารางส่วนลดตามสินค้า
22. **product_reviews** - ตารางรีวิวสินค้า
23. **product_tags** - ตารางแท็กสินค้า
24. **product_tags_to_products** - ตารางความสัมพันธ์ระหว่างแท็กกับสินค้า
25. **product_variants** - ตารางตัวเลือกสินค้า (สี, ขนาด)
26. **products** - ตารางสินค้า
27. **refunds** - ตารางการคืนเงิน
28. **shipments** - ตารางการจัดส่งสินค้า
29. **shipping_history** - ตารางประวัติการจัดส่ง
30. **shipping_methods** - ตารางวิธีการจัดส่ง
31. **shipping_rates** - ตารางอัตราค่าจัดส่ง
32. **shipping_zones** - ตารางโซนการจัดส่ง
33. **store_inventory** - ตารางสต็อกสินค้าในร้าน
34. **store_payment_settings** - ตารางการตั้งค่าการชำระเงินของร้าน
35. **store_pickups** - ตารางการรับสินค้าที่ร้าน
36. **store_reviews** - ตารางรีวิวร้านค้า
37. **store_settings** - ตารางการตั้งค่าร้านค้า
38. **stores** - ตารางข้อมูลร้านค้า
39. **user_preferences** - ตารางการตั้งค่าผู้ใช้
40. **user_preferred_brands** - ตารางแบรนด์ที่ผู้ใช้ชอบ
41. **user_preferred_categories** - ตารางหมวดหมู่ที่ผู้ใช้ชอบ
42. **user_roles** - ตารางบทบาทผู้ใช้
43. **user_sessions** - ตารางเซสชันผู้ใช้
44. **user_social_links** - ตารางลิงก์โซเชียลมีเดียของผู้ใช้
45. **users** - ตารางข้อมูลผู้ใช้
46. **wishlist_items** - ตารางรายการสินค้าในวินลิสต์
